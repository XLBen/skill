# 判定与停机规则（verdict-rules）

每轮导师复审与学生判定时读本文件。答辩循环由双 AI 全自动执行（主代理=学生，examiner subagent=导师），用户仅在 owner-only 决策、僵持仲裁、收报告三类时点介入。

## 严重度三级定义

| 级 | 定义 | 判例 | 后果 |
|---|---|---|---|
| **硬伤** | 逻辑矛盾；事实性错误；会导致返工的遗漏；承担核心功能的假设被证伪/无证据 | §2 依赖的 A-01 实际不成立；D-03 断言的 API 行为与官方文档相反；§6 没有任何可执行验收 | 必须修复才能通过 |
| 软伤 | 次优但可用；不影响主体成立 | 某实现方式非最优；某边界场景处理简陋 | 登记进 §8 已接受风险，不阻塞 |
| 质疑 | 偏好/风格类意见 | 命名、组织方式 | 记录即可，学生可不改 |

判定时**只看当前版本论文文件**，不听口头承诺——学生说"我会改"，以写盘的 v(n+1) 为准。终态硬伤计数**逐条采信 examiner 复审的严重度标注**，学生仅转录写盘；擅自改判视同自答自判，返工。

## 通过条件（停机规则）

满足任一即停：

1. **0 硬伤通过**：某一**有效轮**导师复审后，硬伤计数为 0（软伤、质疑不计）→ `status: passed`。允许提前通过，不必跑满轮数。
2. **轮数上限**：轻量 1 / 标准 3 / 严酷 5 个有效轮用尽仍有硬伤 → `status: conditional`，论文头部附加《遗留硬伤清单》（编号 + 一句话 + 建议处理轮次）。conditional 不阻塞施工——construction 门禁会把清单注入计划注意事项，并要求用户明确同意一次后才开工。
3. **收敛停机**（收益递减）：本轮全部新问题经比对均为已回答问题的变体（换皮），且无新增硬伤，且可直接采纳的强化建议已采纳或无剩余 → 视为收敛，按规则 1 处理。

## 轮有效性门（防空转）

一轮只有产出 **≥2 道带预期影响的实质题**才构成有效轮：

- 首轮硬性要求 ≥2 道实质题；任何一轮 0 实质题 → 该轮**不计轮数、不触发"0 硬伤通过"**，重派导师一次并附提示"上一轮无实质问题，请按攻击面矩阵重新选靶"。
- 重派仍 0 题 → 视为确实无可质疑，按收敛停机（规则 3）。
- `rounds` 权威计数：主代理在每轮复审落盘时同步 frontmatter `rounds +1`，与 defense-log 累计轮数对账，不一致取大。

## 回炉重辩协议（construction CR 触发；唯一权威描述，SKILL.md §1 与施工侧均引用此处）

- **触发**：defense-log 存在《CR 回炉请求》条目（由 construction 写入，含 CR 编号/证伪对象/影响清单，状态：待重辩），扫描检测，不要求是末条；或用户当面转述 CR。
- **进入**：`status → redefending`，frontmatter 写 `redefense-of: CR-xx`、`rounds: 0`、depth 沿用。
- **范围**：仅攻击被证伪章节及其波及条目（对照 CR 的影响清单）；导师派发参数附范围说明。
- **出口**：本轮清零且无其他遗留硬伤 → `passed`；仍有硬伤（含 conditional 原有遗留）→ 回到 `conditional` 并**更新《遗留硬伤清单》**；撞轮数上限 → 同 conditional 出口。两种出口均 version+1、`redefense-of` 保留。construction 以版本推进 + status 为复工锚点。

## 换皮检测

对每个新问题 Q-new 检查答辩记录：是否存在旧问题 Q-old 已被判定"已解决"，且 Q-new 的实质质疑点与 Q-old 相同（表面措辞不同）？是 → 标注"复现 Q-old"，不计入新硬伤基数。连续一轮全部为复现 → 触发规则 3。

## IM（无实质影响）处置

学生答辩时可将某题标记为 **IM**：说明"该题即使成立也不改变任何决策/条目"及理由，交导师复核：

- 导师确认 → **撤题**，不计入任何计数，defense-log 标注"撤题 Q-xx"。
- 导师反对 → 必须写明具体影响点（哪个条目/判定会变）；写不出影响点仍坚持 → 双方论点按仲裁规则记"待仲裁"，该题按软伤计。

**灌水倾向纠正**：单轮内 ≥2 题被撤题或判 IM → 答辩报告记录"导师灌水倾向"，下一轮问题数上限减 2（不低于 2）。减配由主代理计算，作为派发参数"本轮问题数上限"传给导师 subagent（见 SKILL.md §4）——干净上下文的导师不知道惩罚历史，必须显式传入。学生不得滥用 IM 逃避实质问题：IM 标记须逐条给理由，无理由的 IM 视同未答。

## 强行解释（学生侧违规，等同灌水）

学生为保结论而扭曲事实、含糊其辞、编造"听上去合理"的理由 = 违规：该题视同未答且计硬伤。合法出路只有四条（证据型 / 修订型 / 假设型 / IM 型，见 SKILL.md §5）；若一个主张只有靠强行解释才能成立，正确动作是**弱化或降级该主张**，不是辩护。

## 软伤沉淀

判定为软伤的条目：导师给出风险描述 → 学生确认接受 → 移入论文 §8《已接受风险》（格式：软伤描述 / 导师意见 / 接受理由）。施工 skill 开工时读取 §8。

## 仲裁（双 AI 全自动模式下的僵持处理）

学生与导师就某条是不是硬伤僵持（各说各理超过一轮）→ 停止拉扯，登记**待仲裁**条目：双方论点各 100 字以内存入 defense-log，该条本轮按**软伤**计（不阻塞通过），并在答辩报告中醒目列出。用户（答辩委员会主席）事后可翻案：翻案 → 论文 version+1，仅重辩该条。用户在场时也可当场一票裁决，裁决记入 defense-log 后不再重议。

## 断点恢复细则

阶段判定优先读 frontmatter `phase`（questioning/answering/reviewing，每阶段完成即落盘），不靠反推日志：

| thesis.md 状态 | 恢复动作 |
|---|---|
| draft / defending，phase: questioning | 第 k 轮问题已出但答辩未开始 → 重新展示第 k 轮问题 |
| draft / defending，phase: answering | 答辩进行中 → 续写答辩段并完成修订 |
| draft / defending，phase: reviewing | 复审进行中 → 重新派发 examiner 完成复审并转录 |
| redefending | 恢复限定范围重辩（范围读 redefense-of 对应 CR 的影响清单），rounds 从 0 计 |
| 复审完成、未写终态 | 按"通过条件"推进下一轮或收尾 |
| passed / conditional（无待重辩 CR） | 告知已完成，问是否重辩（version+1，rounds 归零）或转施工 |
| passed / conditional（有待重辩 CR） | 自动进入《回炉重辩协议》 |

恢复后第一句话向用户确认："从第 k 轮 <阶段> 继续，论文当前 v(n)，对吗？"

## defense-log 格式（三段即时追加，不整轮批写）

```markdown
## 第 k 轮（论文 v(n) → v(n+1)，日期）
### 提问（examiner 报告返回后立即追加；主代理转录）
<钢人复述 + Q 清单原文（含影响标注）+ 强化建议>
### 答辩（学生答辩完成即追加）
<逐题回答摘要 + 修订了哪些章节/条目>
### 复审（复审返回后立即追加；主代理逐字转录，不得改判严重度）
<逐题：已解决 / 未解决(硬伤) / 软伤→§8 / IM撤题 / 待仲裁>
本轮硬伤计数：<x>（采信导师标注） ｜ 累计有效轮数：<k>（已写回 frontmatter rounds）
（可选）仲裁记录 / 收敛判定依据 / CR 回炉请求（由 construction 追加）
```
