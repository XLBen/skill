# 08 UI 系统（Unity 6.5）

## Contents
- uGUI 组件 · 屏幕适配 · 世界空间 UI · 飘字 · TextMeshPro · 代码交互 · UI Toolkit · 焦点导航与无障碍 · 坑

两套 UI：**uGUI**（成熟稳定，2D 游戏默认）与 **UI Toolkit**（编辑器扩展/复杂界面）。不要混用（输入事件系统不同）。

## uGUI 核心组件

| 组件 | 说明 |
|---|---|
| Canvas | 渲染根（Overlay / Screen Space Camera / World Space） |
| CanvasScaler | 分辨率适配（Scale With Screen Size） |
| GraphicRaycaster | 射线检测（Canvas 必需） |
| EventSystem | 输入事件分发（场景必须有一个，否则 UI 无响应） |
| Image / RawImage | 图片 |
| Button / Toggle / Slider / InputField / ScrollRect / Dropdown | 交互控件 |
| TextMeshProUGUI | 文本（富文本、字体图集） |
| Mask / RectMask2D | 遮罩（RectMask2D 性能好） |
| LayoutGroup / ContentSizeFitter / AspectRatioFitter | 布局 |
| CanvasGroup | 整体透明度/交互开关/射线阻断 |

## 屏幕适配（移动端核心）

- CanvasScaler：Scale With Screen Size + Reference Resolution（1920×1080）+ Match 0.5
- 锚点：边缘元素贴对应边（stretch），中心元素中心锚点
- 刘海屏：`Screen.safeArea` 手动偏移
- 来源：https://docs.unity3d.com/6000.5/Documentation/ScriptReference/Screen-safeArea.html

## 世界空间 UI（血条/飘字）

```csharp
// 世界坐标转屏幕(Screen Space Overlay)
Vector3 screenPos = Camera.main.WorldToScreenPoint(worldPos);
uiRect.position = screenPos;
bool behind = Vector3.Dot(Camera.main.transform.forward,
    worldPos - Camera.main.transform.position) < 0;   // 背后隐藏
```

伤害数字高频场景用精灵数字图集（0-9 sprite 池化），不用逐字 Text（GC 灾难，见 `references/genres/2d-survivor-like.md`）。

## TextMeshPro

- 首次使用生成 TMP Essentials 字体图集；中文需含中文的字体文件生成动态图集（字符集溢出时字体 Asset 设 Multi Atlas）
- 富文本：`<color=red>红色</color>`、`<b>`、`<size>`、`<sprite=0>`
- 频繁拼接用 StringBuilder 或 `SetText` 重载

## 代码交互

```csharp
button.onClick.AddListener(OnStartClicked);
button.onClick.RemoveAllListeners();       // 动态重建 UI 前必须清监听
toggle.onValueChanged.AddListener(v => { });
slider.value / slider.onValueChanged;
img.fillAmount = 0.5f;                     // 血条(Image Type = Filled)
img.fillAmount = Mathf.Lerp(img.fillAmount, target, Time.deltaTime * 5f);  // 平滑血条
```

## UI Toolkit 简介（何时用）

- 编辑器扩展界面（自定义 Inspector/工具窗口）主力，见 `references/10-editor-scripting.md`
- 运行时 UI 适合复杂数据驱动界面（背包网格、技能树）
- 2D 游戏常规 UI 建议 uGUI（资料全、生态成熟）

## 焦点导航与无障碍（手柄/键盘操作 UI）

- 手柄导航：EventSystem 的 Input System UI Input Module + 控件 Explicit Navigation（上下左右指定焦点），默认自动导航在复杂布局会乱跳
- 焦点可视化：为 Button 配选中态（ColorTint 的 Selected Color），玩家须始终知道焦点在哪
- 色弱适配：关键信息不只靠颜色（红绿状态加图标/形状）
- 输入重绑定 UI：见 `references/09-input-audio.md` 重绑定节

## 坑（现象 → 原因 → 解法）

1. UI 点了没反应 → 场景没 EventSystem → 加 EventSystem + Input System UI Input Module
2. 血条/倒计时拖垮整屏 → 动静态元素同 Canvas → 频繁变化元素拆独立 Canvas
3. LayoutGroup 报循环依赖 → 与 ContentSizeFitter 互相控制尺寸 → 明确由谁控制（Layout 或 Fitter 二选一）
4. 动态列表按钮响应错乱 → 监听叠加 → 重建前 RemoveAllListeners
5. 世界 UI 被墙挡住仍显示 → 没做遮挡判定 → 相机点积判背后隐藏
